# Usage

```python
import materials_science_indexer
```

Each module is self-contained; see docstrings for the API:

- `materials_science_indexer.search_indexer` — Main class for search index creation and query processing
- `materials_science_indexer.inverted_index` — Implementation of inverted index data structure
- `materials_science_indexer.ranker` — Module for ranking search results based on relevance
- `materials_science_indexer.materials_database` — Database interface for materials science data
- `materials_science_indexer.test_search_indexer` — Unit tests for search indexer functionality
- `materials_science_indexer.docs` — Module containing documentation and metadata for the project
